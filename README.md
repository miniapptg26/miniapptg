# 💨 Вейп-Кликер — Telegram Mini App v2

Кликер в мире вейпинга как Telegram Mini App (статический сайт на GitHub Pages, без серверов). Тёмная неоновая тема, уведомления, рейтинг с ручным обновлением и кланы.

## Что нового в v2
- 🔔 Уведомления: центр уведомлений (колокольчик, бейдж), уведомления об офлайн-доходе, приглашениях, квестах, достижениях, дневной награде, престиже/турбо
- 🎁 Реферальная система для бота **@ded_cmbot**: ссылки открывают игру и ЛС бота
- 💬 Связь с ЛС: кнопки «Написать боту», «Привязать ID к боту» (deep link start=link_<id>)
- 🏰 Кланы (локальные, создания/вклад/уровни/бонусы, без общего рейтинга)
- 🏆 Рейтинг с ручным обновлением (кэш + кнопки Обновить/Отправить; общий рейтинг — при настройке SYNC_URL)
- 🎨 Продвинутый дизайн: glassmorphism, неон, анимация пара и «+1»

## Деплой на GitHub Pages (5 минут)
1. Создай репозиторий, загрузи `index.html`, `styles.css`, `app.js` (и README).
2. Settings → Pages → Deploy from branch → `main` / `(root)` → Save.
3. URL: `https://<ник>.github.io/<repo>/`

## Подключение к Telegram
1. У @BotFather создай бота (у тебя он уже есть: **@ded_cmbot**).
2. Команда `/newapp` → создай Mini App с URL из GitHub Pages; получи `short_name`.
3. Впиши `BOT_APP_SHORT` (short_name) и при желании свой `BOT_USERNAME` в начале `app.js`.
4. В BotFather задай Menu Button на URL приложения.

## Реферальная система (@ded_cmbot)
Ссылки генерируются в разделе «Профиль → Пригласить»:
- 📱 `https://t.me/ded_cmbot?startapp=ref_<id>` — открывает игру, новичок получает **+250 💨** и уведомление «По ссылке друга»
- 💬 `https://t.me/ded_cmbot?start=ref_<id>` — открывает ЛС с ботом; **если у тебя задеплоен Python-бот** (см. ниже), он пришлёт другу ссылку на игру и **уведомит тебя в ЛС о новом приглашённом** (+150 💨 рефереру)

### Сниппет для бота на Python (aiogram 3) — уведомления в ЛС
Добавь в своего бота (например, `main.py`):

```python
# /start ref_<id> — реферальная ссылка из мини-аппа
@router.message(F.text.startswith("/start ref_"))
async def start_ref(message: Message):
    parts = message.text.split()
    ref = int(parts[0].split("_")[1]) if len(parts) > 0 and "_" in parts[0] else 0
    # сохрани: user_id, chat_id, referrer_id
    if ref and ref != message.from_user.id:
        add_referral(message, ref)  # +150 рефереру, +250 новичку (в твоей БД)
        # уведомление рефереру в ЛС
        await bot.send_message(ref, f"🎁 {message.from_user.full_name} пришёл по твоей ссылке! +150 💨")

# /start link_<id> — привязка чата для уведомлений
@router.message(F.text.startswith("/start link_"))
async def start_link(message: Message):
    save_chat_id(message.from_user.id, message.chat.id)
    await message.answer("✅ Привязка готова — буду слать уведомления в ЛС!")

# Уведомление об офлайн-доходе: вызывай из мини-аппа через startapp=offline_<id>
```

Мини-апп открывает ЛС с ботом по кнопке «🔗 Привязать ID к боту» (`?start=link_<id>`), а «💬 Написать боту» — просто чат. После привязки бот может слать пуш-уведомления (например, напоминание об офлайн-доходе или новой награде).

## Рейтинг (ручное обновление)
Вкладка «Клан → 🏆 Рейтинг»:
- «🔄 Обновить» — загружает рейтинг из `SYNC_URL` (если настроен)
- «📤 Отправить» — пушит твой результат
- Локальный кэш `vc_board` хранит последний ответ

Чтобы сделать общий рейтинг на статике, используй бесплатное JSON-хранилище (JSONBin.io и т.п.) и впиши в начале `app.js`:
```js
var SYNC_URL  = 'https://api.jsonbin.io/v3/b/<BIN_ID>';   // GET — список
var SYNC_TOKEN = '<X-Master-Key>';                        // ключ
var SYNC_BIN  = '<BIN_ID>';
```
Без настройки рейтинг показывает твои локальные данные и подсказку.

## Кланы (без общего рейтинга)
- 🏰 Создание за 10 000 💨 (название + уникальный код)
- 💪 Вклады растят счёт и уровень (каждые 20 000 очков → уровень, макс 25)
- 🎁 Бонус клана: +1% к затяжке и автофарму за уровень (до +15%)
- 🚪 Выход с подтверждением
- ⚠️ В статике клан хранится у тебя на устройстве; общие члены и клановый рейтинг — после подключения бэкенда (архитектура готова: `clan` в `defaultSave`)
