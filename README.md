# 💨 Вейп-Кликер — Telegram Mini App

Кликер в мире вейпинга как **Telegram Mini App**: работает прямо в Telegram на любом устройстве, без серверов.

## Особенности
- 💨 Кликер: затяжки, криты, турбо x3, 40+ фирменных фраз
- 🛒 ВейпШоп: 10 разделов × 20 товаров = **200 устройств** (баки, поды, бокс-моды, BORO, AIO, конструкторы, жижи, вата, койлы, аккумуляторы) с пагинацией
- ⚙️ Прокачка: вата / койл / крит-мод
- ✨ Престиж (перерождение, до +200% к затяжке), 🌙 офлайн-доход (до 4 часов), 🔥 серия дней, 🎁 дневной бонус
- 🎲 Игры: рулетка, кубики, орёл/решка, блэкджек, сапёр — своя ставка, честные шансы
- 📋 Ежедневные квесты, 🏅 18 достижений, 🔗 реферальная система
- 💾 Сохранение в localStorage браузера Telegram + экспорт/импорт прогресса JSON

## Деплой на GitHub Pages (5 минут)

1. Создай репозиторий на GitHub (например `vape-clicker`).
2. Загрузь в него 3 файла: `index.html`, `styles.css`, `app.js` (и `README.md`).
3. Репозиторий → **Settings → Pages** → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)` → **Save**.
4. Через минуту получишь URL: `https://<твой-ник>.github.io/<repo>/` ✅

Альтернатива — GitHub Actions: в репозитории **Actions → New workflow → Deploy static content to Pages**, коммит — и всё.

## Подключение к Telegram

1. У @BotFather создай бота и команду **/newapp** — создай Mini App, укажи URL из GitHub Pages (можно с `/`). Получи `short_name` приложения.
2. В настройках бота задай Menu Button → URL приложения.
3. Открытие: `https://t.me/<бот>?startapp=...` или прямо через меню бота.

## Реферальная система

Ссылка вида `https://t.me/<бот><?startapp=ref_<id>` — если открыть с параметром `ref_<id>`:
- новый игрок получает **+250 💨** на старт;
- бонусы реферера требуют сервера (см. ниже) — в статической версии рефералы считаются локально.

Настрой ник бота в разделе «Профиль», чтобы ссылка стала рабочей.

## ⚠️ Ограничения статической версии

GitHub Pages — это статика без сервера, поэтому:
- ❌ общие кланы/рейтинг (нужен общий бэкенд);
- ❌ начисление бонусов рефереру на чужом устройстве;
- ✅ прогресс хранится локально (localStorage) — не пропадает при перезапуске, но привязан к устройству; есть экспорт/импорт.

Как подключить бэкенд позже: подними API (например тот же Python-бот на Amvera), добавь файл `api.js` с HTTPS-запросами, замени вызовы сохранения/рейтинга/кланов на серверные. Архитектура JS это позволяет.

## Структура
