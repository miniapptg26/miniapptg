# 💨 Вейп-Кликер — Telegram Mini App v2

Кликер в мире вейпинга как Telegram Mini App (статический сайт на GitHub Pages с опциональным онлайн-бэкендом). Тёмная неоновая тема, уведомления и кланы.

## Что нового в v2
- 🌐 Онлайн-режим: общий топ по балансу через бэкенд, ставки списываются сразу, дневные капы против накрутки
- 🔔 Уведомления: центр уведомлений (колокольчик, бейдж), уведомления об офлайн-доходе, приглашениях, квестах, достижениях, дневной награде, престиже/турбо
- 🔥 Комбо-клики: серия быстрых затяжек разгоняет множитель до x5
- 🎡 Спин дня: раз в день бесплатные призы 500–5000 💨
- 🍀 Удача при клике: 4% шанс на случайный бонус x2
- 🎁 Реферальная система для бота **@ded_cmbot**: ссылки открывают игру и ЛС бота
- 💬 Связь с ЛС: кнопки «Написать боту», «Привязать ID к боту» (deep link start=link_<id>)
- 🏰 Кланы (локальные, создания/вклад/уровни/бонусы)
- 🎨 Продвинутый дизайн: glassmorphism, неон, анимация пара и «+1»
- ⚡ Клик без ограничений по скорости — никаких пауз между затяжками

## Деплой на GitHub Pages (5 минут)
1. Создай репозиторий, загрузи `index.html`, `styles.css`, `app.js` (и README).
2. Settings → Pages → Deploy from branch → `main` / `(root)` → Save.
3. URL: `https://<ник>.github.io/<repo>/`

## 🌐 Онлайн-режим и топ по балансу

После деплоя бэкенда из папки `ded_cmbot_online` (README внутри) мини-апп становится онлайн:

1. Задеплой `ded_cmbot_online` на Amvera: в корне репозитория лежит `amvera.yml`, переменные `BOT_TOKEN`, `ADMIN_IDS`, `MINIAPP_URL=https://<ник>.github.io/<repo>/`, `DB_PATH=/data/ded_cmbot.db`, порт `8080`.
2. Впиши адрес бэкенда в начале `app.js`:
   ```js
   var API_URL = 'https://<проект>.amvera.io';
   ```
   Пустое значение = оффлайн-режим, всё работает как раньше.
3. Синк: каждые `SYNC_EVERY_MS = 5000` мс и при закрытии/скрытии приложения мини-апп шлёт серверу дельты через `/api/sync` — доход кликов/офлайна, игры, траты в магазине и счётчики. При старте `/api/init` подтягивает серверный баланс, а кнопка «🏆 Топ» открывает общий топ.
4. Топ по балансу — общий: в мини-аппе (главная и профиль) и в боте командой `/top`; бот `/me` показывает место в топе.

**Фикс бага со ставкой:** ставка теперь списывается в момент начала игры функцией `gameStart`, а в конце возвращается только выигрыш через `gameEnd`. Если ты проиграл и закрыл модалку или само приложение, не дожидаясь кнопки результата — деньги уже списаны, баланс не «откатывается». Раньше списание происходило только в конце игры в `finishGame`, поэтому проигравший мог закрыть приложение и сохранить баланс.

## Экономика в онлайн-режиме

- Сервер хранит баланс и не даёт ему уйти в минус.
- Дневные капы против накрутки, задаются переменными окружения бэкенда:
  - клики и офлайн-доход — до **300 000 💨 в день** (`DAILY_CLICK_CAP`);
  - чистый плюс от игр — до **150 000 💨 в день** (`DAILY_GAME_CAP`).
- Доход сверх капа сервер не засчитывает.
- Рефералка в боте: +250 💨 новичку и +150 💨 пригласившему.
- Топ общий по серверному балансу — и в мини-аппе, и в боте.

## Подключение к Telegram
1. У @BotFather создай бота (у тебя он уже есть: **@ded_cmbot**).
2. Команда `/newapp` → создай Mini App с URL из GitHub Pages; получи `short_name`.
3. Впиши `BOT_APP_SHORT` (short_name) и при желании свой `BOT_USERNAME` в начале `app.js`.
4. В BotFather задай Menu Button на URL приложения.

## Реферальная система (@ded_cmbot)
Ссылки генерируются в разделе «Профиль → Пригласить»:
- 📱 `https://t.me/ded_cmbot?startapp=ref_<id>` — открывает игру, новичок получает **+250 💨** и уведомление «По ссылке друга»
- 💬 `https://t.me/ded_cmbot?start=ref_<id>` — открывает ЛС с ботом; **если у тебя задеплоен Python-бот** (см. ниже), он пришлёт другу ссылку на игру и **уведомит тебя в ЛС о новом приглашённом** (+150 💨 рефереру)

### Сниппет для бота на Python (aiogram 3) — уведомления в ЛС
Добавь в своего бота (например, `main.py`):

```python
# /start ref_<id> — реферальная ссылка из мини-аппа
@router.message(F.text.startswith("/start ref_"))
async def start_ref(message: Message):
    parts = message.text.split()
    ref = int(parts[0].split("_")[1]) if len(parts) > 0 and "_" in parts[0] else 0
    # сохрани: user_id, chat_id, referrer_id
    if ref and ref != message.from_user.id:
        add_referral(message, ref)  # +150 рефереру, +250 новичку (в твоей БД)
        # уведомление рефереру в ЛС
        await bot.send_message(ref, f"🎁 {message.from_user.full_name} пришёл по твоей ссылке! +150 💨")

# /start link_<id> — привязка чата для уведомлений
@router.message(F.text.startswith("/start link_"))
async def start_link(message: Message):
    save_chat_id(message.from_user.id, message.chat.id)
    await message.answer("✅ Привязка готова — буду слать уведомления в ЛС!")

# Уведомление об офлайн-доходе: вызывай из мини-аппа через startapp=offline_<id>
```

Мини-апп открывает ЛС с ботом по кнопке «🔗 Привязать ID к боту» (`?start=link_<id>`), а «💬 Написать боту» — просто чат. После привязки бот может слать пуш-уведомления (например, напоминание об офлайн-доходе или новой награде).

## Кланы
- 🏰 Создание за 10 000 💨 (название + уникальный код)
- 💪 Вклады растят счёт и уровень (каждые 20 000 очков → уровень, макс 25)
- 🎁 Бонус клана: +1% к затяжке и автофарму за уровень (до +15%)
- 🚪 Выход с подтверждением
- ⚠️ В статике клан хранится у тебя на устройстве; общие члены — после подключения бэкенда (архитектура готова: `clan` в `defaultSave`)

## Команды и кнопки
Вкладки: Главная (кликер), Магазин (200 товаров), Игры (5 игр), Квест дня, Клан, Профиль.
Во всех играх (рулетка, кубики, орёл/решка, блэкджек, сапёр) ставку выбираешь сам — от 10 💨 до твоего баланса. Ставка списывается сразу при старте игры, в конце начисляется только выигрыш.
Кнопки на главной: 🎁 Дневная, 🎡 Спин дня, ⚡ Турбо x3, ✨ Престиж, 🔗 Пригласить.
Быстрые клики подряд собирают комбо: каждые 8 кликов дают +1 к множителю до x5, а у клика есть 4% шанс на удачу x2.
Профиль: 💬 Написать боту, 🔗 Пригласить, 📤 Привязать ID к боту, достижения, сброс прогресса.
Экспорт/импорт данных удалены.
